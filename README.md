# Nexus-ABI: Agentic-Semantic Revenue Engine

### 🚀 Overview
**Nexus-ABI** is a next-generation Business Intelligence platform built for the 2026 AI era. It bridges the gap between traditional data analytics and generative AI by managing a digital workforce of AI agents to provide governed, actionable business insights.

### 🧠 The Core Problem
Traditional dashboards tell you *what* happened but fail to explain *why* or suggest *what to do*. Nexus-ABI uses a **Semantic Layer** to prevent LLM hallucinations, ensuring all generated insights are grounded in a single source of truth.

### 🛠️ Tech Stack (100% Open-Source)
- **Brain:** Ollama (Llama 3) running locally on AMD Ryzen.
- **Orchestration:** LangGraph (Multi-agent workflows).
- **Predictive Core:** XGBoost & Scikit-learn.
- **Data Engine:** PySpark & PostgreSQL.
- **Frontend:** Power BI Desktop with Python Integration.

### 📂 Project Structure
- `01_data_pipeline/`: Synthetic data generation and cleaning.
- `02_predictive_core/`: ML models for Churn and CLV.
- `03_semantic_layer/`: Governed metrics and "Metrics-as-Code".
- `04_agentic_engine/`: LangGraph orchestrator and local RAG.
- `05_dashboard/`: Power BI visualization.
- `06_evaluation/`: Accuracy and faithfulness testing.
